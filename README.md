# Librextio - Modern Library Management System

A sleek, organic Library Management System built with React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Dashboard & Bento Grid**: Quick overview of book inventory, active loans, and members.
- **Book Catalog**: Searchable and filterable by genre, ISBN, and availability. Add and manage volumes.
- **Loans & Returns**: Issue books to patrons and record returns with automated copy recalculation.
- **Member Directory**: Track patrons, faculty, and scholars with borrowing limits.
- **Local Persistence**: State automatically persists in browser `localStorage`.
- **Session Clock & Tasks**: Built-in desk session timer and curator daily checklist.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Hosting Ready**: Vercel (`vercel.json` included)

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New..."** -> **"Project"**.
3. Import your GitHub repository.
4. Leave framework preset as **Vite** and click **Deploy**.
